# B 站风格手机端 H5 + PHP 后端 —— 需求文档

## 一、项目目标

做一个 **模仿 B 站（bilibili）手机端** 的网页应用，后端使用 **PHP**（可部署到现有的 PHP 网页服务器），前端为移动优先的 H5 页面。要求在手机上浏览体验接近 B 站 App：首页视频流、搜索、播放、消息、个人中心一条龙。

## 二、目标用户与使用场景

| 角色 | 场景 |
| --- | --- |
| 游客 | 逛首页、看排行榜、搜索、看视频与评论 |
| 注册用户 | 登录后额外拥有收藏、关注、观看历史、投稿、消息未读数 |
| 站长 | 把整套文件上传到已有 PHP 服务器站点目录，初始化数据后即可对外访问 |

## 三、功能清单

### 3.1 后端（PHP + JSON API）

1. **统一响应规范**：所有接口返回 JSON，形如 `{ "code": 0, "msg": "ok", "data": {...} }`，异常返回非 0 的 `code` 与中文 `msg`，不输出 HTML 报错页。
2. **数据层**：优先使用 PDO 连接 MySQL；若服务器没有配置 MySQL 或扩展不可用，自动回退到本地 JSON 文件存储，保证开箱即用（同一套接口，切换对前端透明）。
3. **账号体系**：注册、登录、退出、当前用户查询，密码使用 `password_hash` 加密存储，登录态基于 PHP Session。
4. **视频接口**：首页推荐（热度）、动态（时间倒序）、排行榜（带名次）、频道分类列表、单视频详情、相关推荐、投稿发布。
5. **搜索接口**：关键词搜索、热门搜索词、最近搜索历史。
6. **互动接口**：收藏 / 取消收藏、点赞、关注 UP 主、上报观看历史。
7. **消息接口**：通知 / 私信 / 系统三段消息、未读数量统计、标记已读 / 全部已读。
8. **个人中心接口**：用户资料、统计数据（关注/粉丝/获赞）、收藏列表、历史列表、投稿列表。
9. **封面服务**：由 PHP 动态输出 SVG 封面（渐变底 + 标题文字），避免依赖外部图片。
10. **一键初始化**：访问 `api/init.php` 完成建表与种子数据导入，可重复执行而不产生重复数据。

### 3.2 前端（手机端页面，共 6 个）

1. **首页 index.html**：顶部搜索栏（可跳转搜索页）+ 消息角标；频道 Tab（推荐 / 动态 / 排行榜 / 分区）；双列视频卡片流；上拉加载更多；中间「投稿」悬浮按钮。
2. **搜索页 search.html**：返回按钮 + 搜索框 + 搜索按钮；搜索历史（可点击复用、可清空）；热门搜索标签；结果列表（关键词高亮）。
3. **播放页 video.html**：顶部返回 + 标题 + 分享；播放器（播放/暂停、进度条与时间、倍速、全屏）；标题与播放数据；UP 主卡片（头像、关注、发消息）；简介可展开；相关推荐；评论输入与列表；底部操作栏（点赞 / 收藏 / 投币 / 分享）。
4. **消息页 message.html**：通知 / 私信 / 系统分段切换；消息条目（头像、内容、时间、未读点）；「全部已读」。
5. **我的页面 mine.html**：用户资料卡（头像、昵称、等级、关注/粉丝/获赞）；入口宫格（投稿 / 收藏 / 稍后再看 / 历史）；最近观看列表；未登录时引导登录。
6. **登录页 login.html**：B 站风格 Logo、登录/注册双 Tab 表单、字段校验、错误提示。
